# Pause safely

1. Finish the current atomic step or restore a known coherent state.
2. Do not cross a new external or irreversible boundary merely to pause.
3. Record the repository path, branch, head, working-tree state, completed checks, decisions, and next action.
4. Save a concise resume note outside volatile conversation context.
5. Commit work only when the user already authorized committing.
6. State whether the tree is clean and whether the current behavior works.
7. Point the next task to the resume note and session-pickup playbook.

Do not conceal broken or unverified state.
