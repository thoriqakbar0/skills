# Investigation

Use for read-only explanations, audits, comparisons, and recommendations.

1. Define the question and the evidence needed to answer it.
2. Inspect implementation, interfaces, call sites, tests, history, or current external sources as applicable.
3. Separate verified facts, inferences, assumptions, and unknowns.
4. Test important claims with focused read-only checks.
5. Give a direct answer with exact file references or source links.
6. State tradeoffs and confidence when recommending a choice.
7. Apply `unslop` to the reply.

Do not edit files or perform external writes. If implementation becomes necessary, stop and route the new request separately.
