# Poteto Mode for Codex

A focused Codex adaptation of [pstack](https://github.com/cursor/plugins/tree/main/pstack).

The plugin includes:

- `poteto-mode`, a router for six evidence-driven workflows.
- `unslop`, applied to replies and written artifacts.

This first version excludes Cursor model configuration, Cursor transcripts, Graphite shipping, automatic external writes, and the Benny automation pack.

The upstream pstack project and adapted material use the MIT license.
