# Tool API references

Use this reference after choosing the test tool and before writing code.

Prefer the installed package's types and command help when they differ from online documentation.

## Hegel

Load the installed `hegel` skill, then read `references/<language>/reference.md` for the target language.

If that skill is unavailable, use [Hegel's official library index](https://hegel.dev/) and the installed package types.

## Bombadil

Read the [official Bombadil manual](https://antithesishq.github.io/bombadil/browser/bombadil-manual.txt).

Check the installed `@antithesishq/bombadil` types for exact imports and signatures.

## Hypothesis

Use the official references for the required API:

- [Strategies](https://hypothesis.readthedocs.io/en/latest/data.html)
- [Stateful testing](https://hypothesis.readthedocs.io/en/latest/stateful.html)
